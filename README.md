# Slow Boat Education

This repository contains the Slow Boat Education website and platform.

## Directory structure

- `index.html` — homepage
- `about/` — about page
- `online-courses/` — online courses page
- `study-trips/` — study trips page
- `faqs/` — frequently asked questions page
- `assets/` — images, icons, and logos
- `scripts/` — JavaScript
- `styles/` — CSS

The project is currently being developed incrementally.
